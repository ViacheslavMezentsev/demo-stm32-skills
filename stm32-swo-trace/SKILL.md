# SWO/ITM: трассировка и счётчики DWT

Применяй, когда нужно: получать сообщения из прошивки **без занятия UART**; видеть входы и выходы
прерываний с отметками времени; измерять длительность участков в тактах; понять, почему журнал
«пропадает» на высокой частоте.

**Статус: не проверено на железе.** Это описание того, как включить трассировку, а не отчёт о
работающем канале. Перед обещанием результата выполни проверку совместимости ниже.

## 1. ОБЯЗАТЕЛЬНАЯ проверка совместимости (делать всегда, до всего остального)

**Никогда не включай SWO, не убедившись, что вывод свободен в конфигурации конкретного MCU и
профиля.** Проверки идут по порядку: следующая имеет смысл, только если прошла предыдущая.

| Что проверить | Как |
|---|---|
| Свободен ли вывод SWO в этом профиле | сверить распиновку и занятость пина (на F411 — PB3, он же JTDO) по `.ioc` и коду BSP |
| Поддерживает ли отладчик ITM/DWT | `openocd` в интерактивном режиме, команда `itm ports on` |
| Есть ли вызовы ITM в прошивке | поиск `ITM_`/`SWO_` в исходниках и в отладочных модулях |
| Настроен ли TPIU | `tpiu config internal - uart off <частота ядра>` до включения потока |
| Идёт ли поток | `itm port 0 on` и наблюдение вывода; пусто — нет вызовов ITM в коде |

Если вывод SWO занят функцией проекта, трассировка невозможна, пока он не освобождён. Проверять
конфигурацию вывода нужно для **каждого** профиля: на другой плате или в другой конфигурации тот же
MCU может иметь его свободным.

## 2. Скрипт

```sh
python scripts/swo_trace.py --check                  # доступен ли SWO и настроен ли TPIU
python scripts/swo_trace.py --capture --seconds 5    # принять поток ITM
python scripts/swo_trace.py --dwt --seconds 5        # снять DWT CYCCNT до и после
```

Скрипт поднимает OpenOCD с `interface/stlink.cfg` и `target/stm32f4x.cfg` (для другой серии — правка
`openocd_command`), частота ядра для TPIU — `--sysclk` (по умолчанию 72 МГц: задайте фактическую,
иначе поток будет нечитаемым), путь к OpenOCD — `--openocd`.

## Файлы навыка

```
scripts/
  swo_trace.py           --check / --capture / --dwt: настройка TPIU/ITM, приём потока, счётчики DWT
```

Пути — относительно каталога навыка; скрипту нужны только Python 3 и OpenOCD.
